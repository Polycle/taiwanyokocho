# 台湾横丁 当日ナビ 運用マニュアル

このリポジトリは、台湾横丁の参加者向け当日アプリです。

参加者は公開URLを開いて、名札の名前・ニックネームを入力すると、自分の初回席と席替え後の席を確認できます。

公開URL:

https://polycle.github.io/taiwanyokocho/

管理リポジトリ:

https://github.com/Polycle/taiwanyokocho

## できること

- 当日の流れを見る
- 会場地図を開く
- 名札名・ニックネームで席を検索する
- 初回席と席替え後の席を見る
- 店内のテーブル配置を見る
- 円卓上の座る位置を見る
- 参加後アンケートへ移動する

## 大事な考え方

参加者の本名はアプリ内部の座席管理には使っていますが、画面上には基本的に名札名・ニックネームだけが表示されます。

検索も名札名・ニックネームだけで行う仕様です。本名検索はできません。

公開ページは誰でも見られる可能性があります。参加者の本名を画面上に出す変更は避けてください。

## ファイルの役割

- `index.html`: 画面の文章、イベント時間、地図リンク、アンケートリンク
- `app.js`: 座席データ、参加者の本名と名札名、検索処理
- `styles.css`: 見た目、スマホ表示、円卓表示
- `assets/taiwan-yokocho-group.jpg`: トップ画像
- `.github/workflows/pages.yml`: GitHub Pages公開用の設定
- `.nojekyll`: GitHub Pages用の補助ファイル

## GitHubだけで編集する方法

1. https://github.com/Polycle/taiwanyokocho を開く
2. 変更したいファイルを開く
3. 右上の鉛筆アイコンを押す
4. 内容を編集する
5. 画面下の `Commit changes` を押す
6. 数十秒から数分待つ
7. https://polycle.github.io/taiwanyokocho/ を開いて確認する

公開ページがすぐ変わらない場合は、スマホやブラウザの再読み込みをしてください。

## 参加者名・ニックネームを変更する

`app.js` の `participants` を編集します。

形式:

```js
{ name: "本名", label: "名札名" },
```

例:

```js
{ name: "三浦万弥", label: "まや" },
{ name: "ほなみ", label: "Fanfan" },
```

画面に表示されるのは `label` です。

検索に使われるのも `label` です。

`name` は座席表と参加者データをつなぐための内部用です。

## 座席を変更する

`app.js` の一番上にある `seating` を編集します。

```js
const seating = {
  first: [
    ["1卓の1人目", "1卓の2人目"],
    ["2卓の1人目", "2卓の2人目"],
  ],
  second: [
    ["席替え後 1卓の1人目", "席替え後 1卓の2人目"],
    ["席替え後 2卓の1人目", "席替え後 2卓の2人目"],
  ],
};
```

実際は1卓から6卓まであります。

重要:

- `first` は初回席
- `second` は席替え後
- 外側の `[` `]` の1行が1つの卓です
- 1番目の行が1卓、2番目の行が2卓です
- 名前の並び順は円卓の座席順です
- 先頭の人が円卓の上側、そこから時計回りに表示されます
- 席順を考えてある場合、名前の順番を勝手に入れ替えないでください

## 欠席者を外す

欠席者が出た場合は、次の2か所から削除します。

1. `seating.first` と `seating.second` の座席データ
2. `participants` の参加者データ

片方だけ消すと、検索や表示がずれることがあります。

## 新しい参加者を追加する

1. `participants` に本名と名札名を追加する
2. `seating.first` のどこかの卓に本名を追加する
3. 席替えがある場合は `seating.second` にも本名を追加する

例:

```js
{ name: "田中太郎", label: "たろう" },
```

座席側:

```js
["まえの人", "田中太郎", "つぎの人"]
```

## イベント時間を変更する

`index.html` の `当日の流れ` の部分を編集します。

例:

```html
<li><time>20:40</time><span>アンケート記入</span></li>
```

## 会場地図リンクを変更する

`index.html` の `会場地図` のリンクを編集します。

```html
<a class="map-link" href="ここにGoogle Mapsリンク" target="_blank" rel="noreferrer">会場地図</a>
```

スマホで開けない場合は、Google Mapsアプリで場所を開いて、共有から作った `https://maps.app.goo.gl/...` のリンクを使うと通りやすいです。

## アンケートリンクを変更する

`index.html` の一番下にあるリンクを編集します。

```html
<a href="ここにGoogleフォームURL" target="_blank" rel="noreferrer">参加後アンケートはこちら</a>
```

## トップ画像を変更する

1. GitHubで `assets` フォルダを開く
2. 新しい画像をアップロードする
3. `styles.css` の画像ファイル名を変更する

現在の指定:

```css
url("./assets/taiwan-yokocho-group.jpg");
```

画像名を変えた場合は、ここも同じ名前にしてください。

## 店内テーブル配置を変更する

`app.js` の `tableLayout` を編集します。

```js
const tableLayout = [
  { table: 1, x: 30, y: 29 },
  { table: 2, x: 68, y: 18 },
];
```

- `table`: 卓番号
- `x`: 左から何パーセントの位置か
- `y`: 上から何パーセントの位置か

数字を少しずつ変えると、店内配置図の円卓の位置が動きます。

## 公開ページを手動設定する方法

GitHub Pagesが404になる場合は、手動で設定してください。

1. GitHubでリポジトリを開く
2. `Settings` を開く
3. 左側の `Pages` を開く
4. `Build and deployment` を見る
5. `Source` を `Deploy from a branch` にする
6. `Branch` を `gh-pages` にする
7. フォルダを `/(root)` にする
8. `Save` を押す

数十秒から数分待つと公開URLが開けます。

公開URL:

https://polycle.github.io/taiwanyokocho/

## 更新後の確認チェックリスト

- 公開URLが開ける
- 名札名で検索できる
- 本名で検索してもヒットしない
- 初回席が正しい
- 席替え後の席が正しい
- 円卓上の隣同士の順番が正しい
- 会場地図がスマホで開ける
- アンケートリンクが開ける

## Geminiを使って効率よく更新する

Codexが使えない人でも、Geminiに下のプロンプトを貼ると、更新内容の整理やミスチェックがしやすくなります。

注意:

- Geminiには、必要な範囲だけ貼ってください
- 公開前に、必ずGitHub上の変更内容を人間が確認してください
- 席順は隣同士の関係に関わるので、Geminiに勝手に並び替えさせないでください
- アプリの画面表示は名札名ですが、`app.js` の座席データは本名で管理しています

```text
- 同じ label がある場合は最後に「重複あり」として教えてください

```

```text
- 名前の空白は削除

    [],
    [],

    [],

    [],
    [],
```

## よくあるトラブル

### 公開ページが404になる

GitHub Pagesの設定がまだ有効になっていない可能性があります。

`Settings` → `Pages` で、`gh-pages / (root)` を選んで保存してください。

### 更新したのにスマホで変わらない

ブラウザのキャッシュが残っている可能性があります。

ページを再読み込みしてください。数分待つと反映されることもあります。

### ニックネーム検索で同じ名前の人がいる

同じ `label` が複数あると特定できません。

片方の名札名を少し変えてください。

例:

```js
{ name: "布施帆海", label: "ほなみ" },
{ name: "ほなみ", label: "Fanfan" },
```

### 円卓の名前が重なる

`styles.css` の `.circular-names li` の `width` や `font-size` を小さくしてください。

ただし、席順そのものは `app.js` の名前順で決まるので、見た目調整だけなら `styles.css` を触ります。

## 引き継ぎメモ

このアプリは、特別なサーバーや有料サービスなしで動きます。

基本的には次の流れだけ覚えれば運用できます。

1. `app.js` で座席と名札名を直す
2. `index.html` で時間・地図・アンケートを直す
3. GitHubで `Commit changes`
4. 公開URLで確認する
